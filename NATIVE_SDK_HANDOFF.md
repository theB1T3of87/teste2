# Handoff — Cubism Native

O SDK Native está incluído ao lado deste projeto em `../CubismSdkForNative-5-r.5/`.
O app ainda referencia o Cubism SDK for Java em `settings.gradle.kts` e `app/build.gradle.kts`.
Não altere esses caminhos para apontar ao SDK Native: são distribuições/APIs distintas.
Consulte `../REVISAO_E_BLOQUEIOS_DE_BUILD.md` antes de iniciar a migração C++/JNI.
